Location sharing is off until you start it. An approved courier account can claim an unclaimed demo order. Starting shares your precise device location every few seconds; share only while delivering.

Courier location sharing

Sign in with an administrator-approved courier account, then enter an unclaimed demo order ID. Public courier registration is disabled.

Connect a Firebase project to enable courier location sharing.

Location sharing requires browser permission and an HTTPS page (or localhost). This page uses device geolocation; it does not read cell-tower IDs. Coordinates are available only to the assigned order's customer and courier under the supplied database rules.

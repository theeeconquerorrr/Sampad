Location sharing is off until you start it. When you start, this page sends your precise device location to the assigned order every few seconds. Share only while delivering; tap Stop sharing when finished.

Courier location sharing

Use a courier account assigned to the order. The order service must assign your account before Firebase rules will accept location updates.

Connect a Firebase project to enable courier location sharing.

Location sharing requires browser permission and an HTTPS page (or localhost). This page uses device geolocation; it does not read cell-tower IDs. Coordinates are available only to the assigned order's customer and courier under the supplied database rules.
